# Patient Zero Reflection

Combination of Patient Zero mission and Reflection elusive target.

Mission starts with agent 47 in biohazard suit to prevent infection. If infected, it may not be possible to get cure without mods.

Includes mandatory load out with various tools and weapons, as well as keys to both garage and basement for creepy whittleton creek house.
